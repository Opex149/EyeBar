# EyeBar v1.1 — Hotfix отображения мини-бара (после StandBy render fix)

Основа: предоставленный архив `EyeBar_v1.1_StandBy_render_fix_TEST(1).zip`.
Файл `eyebar/ui/standby.py` **не менялся**; сохранены остальные исходники и функции.

## Исправления

1. Слой `NightShade` в мини-баре больше **не рисует полностью прозрачную заливку** поверх общего Qt backing store при выключенном ночном режиме. Раньше `CompositionMode_Source` с `alpha=0` мог стирать видимые пиксели базовой панели в некоторых сочетаниях Qt/Windows/драйвера. Теперь слой скрыт, когда не нужен; при включении ночного режима использует обычное альфа-наложение.
2. После показа мини-бара восстанавливаются правильный режим «панель/куб», размер и позиция в доступной области текущего монитора; сохраняются пользовательский якорь и настройки. Не сбрасываются темы, персонажи или ширина.
3. При скрытии для StandBy или скриншота прерываются переходы между кубом и панелью и анимация «сдуло ветром»; мини-бар возвращается на исходную позицию вместо зависания за границей экрана.
4. При выходе из полноэкранного StandBy мини-бар явно поднимается поверх других окон.
5. `MiniBar.showEvent()` больше не запускает повторно весь `apply_settings()` во время обработки события показа, когда Qt ещё обновляет геометрию и вложенные виджеты.

## Проверка

Проверены синтаксис всех `.py`, все модульные тесты (`python -m unittest discover -s tests -v`), целостность архива и идентичность файла `standby.py` исходному архиву.

В `tests/test_minibar_visibility.py` добавлены GUI-регрессии (включая прозрачность отрисованного окна, панель/куб, ночь, StandBy, прерванные анимации). В среде сборки нет PyQt6, поэтому **GUI-тесты не запускались**. На Windows следует вручную проверить отображение, особенно если включены системное размытие или захват экрана.

## Если всё ещё невидим

1. Через трей выбери «Показать EyeBar», проверь режим куба и панели.
2. Отключи экспериментальные эффекты: **Настройки → стекло → Classic**, отключи `Glass motion` и `Exclude from capture` (последнее влияет именно на видимость в скриншотах).
3. Проверь `%APPDATA%\EyeBar\eyebar.log` после запуска, если приложение падает.

Для сборки `.exe` на Windows используй `build.bat` из полного проекта.
