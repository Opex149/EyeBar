# EyeBar — предрелизное обновление персонажей

## Что изменено
- Cyber Cat перерисован с нуля в векторной графике: теперь он сидит, с округлым корпусом, ушами, усами, хвостом, мягкими лапами, воротником и температурной вышивкой на шерсти. Дизайн оригинальный, без копирования чужого персонажа.
- Добавлены Luna Bunny и Byte Fox; выбор доступен в настройках.
- В мини-кубе персонаж центрирован, а температура отображается на шерсти кота. Отдельный погодный значок в мини-кубе не используется.
- Добавлены более 150 вариантов городов России в редактируемом списке погоды. Можно вписать любой другой город.
- Исправлен критический вызов `set_temperature_text()` из контроллера, для которого не было методов в MiniBar и StandBy.
- Обновлён PyInstaller spec, чтобы новые персонажи попадали в сборку.

## Проверки
- `python -m compileall -q eyebar main.py`
- `python -m unittest discover -s tests -v` — 14 тестов пройдены, 3 GUI-теста пропущены из-за отсутствия PyQt6 в среде проверки.

## Windows
Запустите `build.bat` в папке проекта или `py -m PyInstaller --clean --noconfirm EyeBar.spec` после установки зависимостей. Готовый exe должен появиться в `dist/EyeBar.exe`.

GUI и готовый Windows EXE в этой среде не запускались, поэтому нужна проверка на Windows перед публикацией релиза.
