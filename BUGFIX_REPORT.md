# EyeBar v3 — аудит и исправления (15.11.2026)

Основа: **EyeBar_v3_Original_UI_Glass_Settings.zip**. Интерфейс оригинальной боковой панели, кубик, персонажи Cyber Cat / Neon Ghost и настройки стекла сохранены. Код и графика из стороннего референсного проекта не переносились.

## Исправлено / усилено

1. **Настройки**: повторное открытие, восстановление из минимизированного состояния, `show()` / `raise_()` / `activateWindow()`; ошибки инициализации показываются в `QMessageBox.critical`, а также записываются в лог.
2. **Отмена настроек**: выбор талисмана отображается сразу, но не записывается на диск до «Сохранить»; закрытие окна или «Отмена» возвращают предыдущий выбор.
3. **Сохранение**: атомарная запись `config.json`, диагностика ошибок сохранения через окно сообщения и автоматическая очистка временного файла.
4. **Повреждённый конфиг**: проверка форматов чисел, флагов, списков закреплённых программ, координат и значений стеклянных эффектов. Неизвестные ключи сохраняются для будущих версий.
5. **Локализация**: проверка структуры JSON, безопасные коды языков, защита от некорректных строк форматирования, новые сообщения об ошибках на RU/EN.
6. **Горячие клавиши**: проверка перед сохранением; поддержка ряда клавиш Space, Tab, Home, End, Delete, стрелок, PageUp/PageDown наряду с буквами, цифрами и F1–F24; корректный учёт переполнения счётчика простоя Windows.
7. **Погода**: безопасная фоновая загрузка без риска уничтожения работающего `QThread`, повторные запросы после ошибок, игнорирование устаревшего ответа при смене города.
8. **Медиаплеер**: безопасная отправка команд при остановке event loop и освобождение ресурсов цикла при выходе.
9. **Трей / StandBy**: команда «Показать мини-бар» выводит из StandBy; временная защита от немедленного повторного перехода по таймеру простоя; при открытых настройках таймер простоя не мешает редактированию.
10. **Анимации**: устойчивее обработано переключение между кубиком и мини-баром во время анимации; StandBy восстанавливает персонажа при закрытии окна в момент «полёта».
11. **Заметки**: синхронизация содержимого при показе/фокусе между панелью и StandBy; сохранение при выходе и смене фокуса.
12. **Производительность**: запись яркости по окончании перетаскивания или после небольшой паузы, а не на каждом шаге ползунка.
13. **Закреплённые программы**: явное предупреждение, когда указанный файл не запускается.
14. **Без трея**: нельзя случайно скрыть панель, если нет значка системного трея для возврата.
15. **Сборка EXE**: `requirements.txt` содержит обязательную зависимость; `requirements-media.txt` — необязательные библиотеки Windows-плеера. `build.bat` продолжает сборку, если эти дополнительные библиотеки недоступны. `EyeBar.spec` сохраняет режим onefile/windowed, переводы и явные импорты талисманов.

## Что проверено здесь

- `python -m compileall -q .` — успешно.
- `python -m unittest discover -s tests -v` — **11 успешных** тестов, **3 пропущенных** GUI-теста, поскольку здесь нет установленного PyQt6.
- JSON-файлы локализаций читаются, наборы ключей RU/EN совпадают.
- ZIP проверен на целостность (см. результат `zipfile.testzip()`).

## Ограничения

Здесь нельзя запустить графический интерфейс PyQt6 или проверить API Windows, включая настоящий глобальный хоткей, Windows acrylic, системный плеер и итоговый `.exe`. Проверка того, что **абсолютно все** баги устранены, невозможна без тестирования на реальном Windows 10/11.

На Windows рекомендуется:

```bat
cd EyeBar
py -m pip install -r requirements.txt
py -m unittest discover -s tests -v
build.bat
```

Готовый файл должен появиться в `EyeBar\dist\EyeBar.exe`.
