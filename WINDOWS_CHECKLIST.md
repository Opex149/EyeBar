# Запуск и проверка Windows 10/11

Установите Python3.11/3.12 x64. В распакованной папке проекта:

```bat
py -m pip install -r requirements.txt
py main.py
```

Для метаданных системного плеера необязательно:

```bat
py -m pip install -r requirements-media.txt
```

Проверки и сборка:

```bat
py -m compileall -q eyebar main.py tests
py -m unittest discover -s tests -v
build.bat
```

Результат сборки:dist\EyeBar.exe. Windows EXE в Linux не создавался.
До обновления сохраните копию %APPDATA%\EyeBar. Программа также создаёт резервные
копии config.json.bak и pre-v1.bak; повреждённый файл сохраняется отдельно.

Проверьте реальную видимость мини-бара после запуска/StandBy/смены темы и персонажа,
все5персонажей, профилиStandBy, таймер и паузу, будильник/Snooze/громкость/WAV,
работу без сети, заметки после перезапуска, глобальную клавишу, системный плеер,
DPI100/125/150/200% и перенос между мониторами. Без аудиобэкенда fallbackbeep
подчиняется системной громкости;0% полностью отключает звук будильника.
Будильник работает при запущенном EyeBar, пробуждение выключенного/спящего ПК не реализовано.
