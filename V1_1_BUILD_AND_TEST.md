# Сборка EyeBar v1.1 на Windows 10/11

## Сборка onefile/windowed

Установи **Python 3.11 или 3.12 (64-битный)** и положи исходники в обычную папку, например `C:\Projects\EyeBar`. Открой терминал в папке `EyeBar`.

Самый простой способ — дважды нажать `build.bat`. После установки зависимостей скрипт вызовет `py -m PyInstaller --clean --noconfirm EyeBar.spec`. Выход: **`dist\EyeBar.exe`**.

Вручную:

```bat
py -m pip install -r requirements.txt
py -m pip install -r requirements-media.txt
py -m pip install pyinstaller
py -m unittest discover -s tests -v
py -m PyInstaller --clean --noconfirm EyeBar.spec
```

`requirements-media.txt` необязателен: если не удаётся его установить, пропусти эту команду. Для полноценного приложения **предпочтительна `EyeBar.spec`**: в ней уже задан один EXE без консоли (`EXE` без `COLLECT`, `console=False`) и упакованы все 5 персонажей и языки, плюс опциональные WinRT-модули, если доступны. Это эквивалент `--onefile --windowed`. Комбинировать `.spec` с этими флагами в одной команде не нужно.

`sys._MEIPASS` используется для чтения ресурсов, тогда как `config.json`, лог `eyebar.log` и локально сгенерированный звук `alarm.wav` хранятся в `%APPDATA%\EyeBar\` и не пишутся рядом с EXE.

## Ручной Windows-чеклист

1. Распакуй и запусти программу без старого `config.json`, затем с имеющимся старым конфигом. Открой/закрой настройки, переключи **всех 5** персонажей, темы и эмоции.
2. Разверни панель → сверни в куб → перейди в StandBy → выйди через Escape и двойной клик. Проверь перетаскивание, изменение ширины, закреплённые кнопки и хоткей.
3. Отключи интернет. Убедись, что приложение остаётся открытым, показывает «Нет данных о погоде», а таймер, заметки, будильники и плеер по медиаклавишам доступны.
4. Создай будильник через StandBy и через меню мини-бара: на следующую минуту, с разными днями недели, без дней (однократно), включи/отключи, перезапусти EyeBar. Дождись сигнала; проверь **Отложить**, **Остановить** и одновременное срабатывание таймера.
5. Отключи StandBy в настройках и проверь, что будильник показывает отдельное окно при звонке.
6. Включи ночной режим вручную, затем выключи; проверь, что яркость/анимации возвращаются. Установи автоинтервал через полночь и проверь при наступлении периода.
7. Только по желанию проверь галочку управления планом питания Windows: убедись, что есть подтверждение, что после выключения ночного режима возвращается **именно прежний план**, и что отсутствие Power Saver обрабатывается безопасно.
8. Сделай скриншот; проверь сохранённый PNG, буфер обмена и изменение нашивки температуры в кубе при известном значении погоды.
9. Проверь сборку `dist\EyeBar.exe` на Windows 10 и Windows 11, в том числе без установленных PyQt6 и Python.

## Автоматические тесты

```bat
py -m compileall -q eyebar main.py tests
py -m unittest discover -s tests -v
```

Среда создания архива: синтаксис проверен, модульные тесты прошли, Qt GUI smoke tests пропущены из-за отсутствия PyQt6. **Готовый EXE не приложен, потому что среда сборки Linux и без PyQt6.**
